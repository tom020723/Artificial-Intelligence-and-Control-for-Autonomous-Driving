## GitHub Workflow

- Create and delete branches freely.
- Direct pushes to `main` are allowed but discouraged; prefer pull requests.
- If you push to `main` by mistake, add a revert commit. Never delete or rewrite commit history on `main`.
- When using someone else's branch, merge it to preserve its history. Do not copy its code while discarding its commit history.
- Reusing small code snippets is fine; discussing it with the author is recommended.
- Use pull requests actively for collaboration and review.
