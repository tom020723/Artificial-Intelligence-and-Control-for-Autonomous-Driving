# BC 충돌 판정 경계 0.2m 재평가

2026-11-18. 사용자 요청에 따라 최신 ACC 제외 BC 모델의 자차 충돌 판정 경계만 2.5m에서 0.2m로 변경해 평가했다.

## 실행 조건과 검증

- 모델: `results/bc49_ring_noacc_fresh_seed0_20261118_110320/selected_model.pt`, epoch 94. 이전 평가와 모델 SHA256 동일.
- 0/1,000/2,000/3,000 veh/h, 각 23개 경로 × 50개 신호 offset = 1,150회, 총 4,600회. seed 0, worker 4.
- 같은 워밍업 250초 배경교통 snapshot 생성 방식과 신호/출발 조건. 기존 평가와 road/mdp/train 설정 파일이 바이트 단위로 동일함을 확인했다.
- `ego_type`의 `collisionMinGapFactor=0.08`로 설정했다. `minGap=2.5m`와 관측 구성, 정책 가중치, 배경차 충돌 규칙은 유지했다. 따라서 자차의 충돌 판정 경계는 2.5 × 0.08 = 0.2m.
- 정지 차량 시험: 2.49m와 0.21m에서는 무충돌, 0.19m에서는 충돌. 자차 minGap이 여전히 2.5m임을 확인했다.
- 관련 단위 테스트 3개 통과. 전체 평가 실행 시간 약 100초.
- 재현 옵션: `scripts/evaluate_quick_bc.py RUN/selected_model.pt --num-workers 4 --ego-collision-gap-m 0.2 --out-dir NEW_OUTPUT`.
- 옵션을 생략하면 기존 SUMO 차량 타입의 충돌 판정을 사용한다. 이번 실행 옵션은 결과 summary와 context 설정에 기록했다.

3,000에서는 완주 7건 증가, 충돌 9건 감소에 그쳤다. 기존 충돌 377건 중 356건은 0.2m 조건에서도 결국 충돌로 종료됐고, 19건은 완주, 2건은 잘못된 차선으로 종료됐다. 기존 완주 중 11건이 새 조건에서 충돌로 끝나기도 했다.

같은 seed와 초기 조건을 사용해도 충돌 차량 제거 시점이 달라지면 이후 교통 상호작용과 SUMO 전역 난수 소비가 달라질 수 있다. 따라서 개별 경로/offset의 종료 전환을 동일한 배경차 궤적을 고정한 인과 비교로 해석하지 않는다. 모델과 평가 설정을 맞춘 전체 결과 비교다.

## 개선이 작은 이유: 2.5m 미만에서 앞차 관측이 사라지는 문제 확인

`env/sumo_env.py:_neighbor`는 SUMO getLeader의 gap이 음수이면 None을 반환한다. SUMO gap은 물리적 범퍼 간격에서 자차 minGap을 뺀 값이다. 자차 minGap이 2.5m이므로 실제 간격이 2.5m 미만이 되면, 가까운 앞차가 존재해도 `_get_obs`의 현재 차선 선행차 값이 `[1, 1]`, 즉 앞차 없음으로 바뀐다.

기존에는 이 경계를 넘자마자 충돌 종료되어 이후 현상이 드러나지 않았다. 0.2m로 완화한 이번 평가에서는 그 상태로 정책이 계속 행동하면서 다시 가속하는 사례를 확인했다.

3,000 veh/h, `ego_d_A5_A3`, 신호 offset 16초 사례를 원래 worker 묶음으로 추가 재현했다. 해당 worker의 종료 상태 집계도 이번 전체 평가와 일치했다. 앞차는 정지 중이다.

| 에피소드 시각 | 물리적 앞차 간격 | 자차 속도 | 현재 차선 앞차 관측 | accel_raw |
|---:|---:|---:|---|---:|
| 25.5s | 2.548m | 0.120m/s | 앞차 있음 | -0.00594 |
| 26.0s | 2.495m | 0.104m/s | **앞차 없음 `[1,1]`** | **+0.20496** |

이 사례에서는 작은 잔여 전진 → 2.5m 아래 진입 → 앞차 없음 입력 → 재가속 → 실제 차체 겹침으로 이어졌다. 0.5초마다 판정하므로 0.2m에 정확히 멈추는 것이 아니라 한 step에 그 경계를 지나칠 수 있다.

이 동작은 가까운 앞차를 '없음'으로 취급하는 관측 코드의 문제다. 현재 차선 선행차의 음수 gap을 앞차 없음과 분리해 표현하는 개선이 필요하다. 다만 관측을 바꾸면 기존 학습 데이터/정책과의 관계도 검증해야 한다. 이번 재평가에서는 요청한 충돌 기준 변경 효과를 확인하기 위해 관측 코드를 수정하지 않았다. 전체 368건 중 이 패턴의 비율은 아직 전수 분류하지 않았다.
