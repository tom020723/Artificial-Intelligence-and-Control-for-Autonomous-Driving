# 물리적 차량 거리 관측 수정과 BC 소규모 비교 실험

실행일: 2026-11-18. 사용자가 승인한 ① 관측 거리 수정, ② 수집·평가 충돌 경계 통일, ③ 소규모 재수집·새 BC 학습·평가를 완료했다.

## 변경 내용

- `OBSERVATION['neighbor_distance_mode']='bumper'`: 좌2·좌1·현재·우1·우2 차선의 앞/뒤 차량 거리를 물리적 범퍼 간 거리로 통일했다. 현재/인접 차선의 SUMO 조회에서는 제외된 minGap을 복원한다. 후행차 거리는 후행차의 minGap으로 보정한다. ±2 차선의 직접 스캔은 이미 물리적 거리이므로 중복 보정하지 않는다.
- 가까운 차량은 사라지지 않는다. 겹친 차량도 거리를 0으로 제한하고 존재·상대속도를 유지한다. 실제로 없거나 물리적 감지 범위 50m 밖인 경우에만 없음 sentinel을 사용한다.
- 관측 차원 49, 기존 50m 정규화, 신호·라우팅·ring 입력을 유지했다. 기존 데이터/모델에서 설정 키가 없으면 `legacy` 인코딩을 사용한다. 새 관측용 가중치를 기존 관측과 혼용하면 안 된다.
- `EGO['collision_gap_m']`와 `TRAFFIC['collision_gap_m']`를 모두 0.2m로 명시했다. 공통 road builder가 차량별 `collisionMinGapFactor = 0.2/minGap`을 기록한다. 추종 제어의 minGap과 차량 모델은 유지했다.
- 수집·단일 환경·병렬 평가에 같은 기준이 적용된다. 평가 CLI에 배경차 경계 명시 옵션도 추가했다. 가중치, 관측 모드, 차량 타입별 충돌 설정이 결과에 기록된다.
- 기존 차선변경 안전 게이트와 보상 계산은 유지했다. 새 관측의 평가 gap 통계는 물리적 거리로 기록한다.

## 검증

관련 테스트 43개를 통과했다. 별도 실제 SUMO 검증에서 자차와 Krauss/IDM/EIDM/ACC 모두 2.49m·0.21m의 앞차를 관측했고, 0.19m에서만 충돌 종료됐다. 현재 차선뿐 아니라 양옆 2개 차선의 앞/뒤 물리적 거리도 실제 배치와 일치했다.

범위를 넓혀 실행한 기존 `test_phase2_restores_traffic_at_the_requested_signal_tick` 1개는 고정 출발 차선 탐색에서 `SUMO did not insert the ego for route ego_d_A1_A2`로 실패했다. 새 충돌 설정을 비활성화해도 같은 위치에서 재현됐다. 관측 계산 전의 출발 탐색 경로이며, 이번 BC 평가에서 사용하는 independent episode RNG 경로는 3개 모델 × 4,600회 평가를 정상 완료했다. 이 기존 테스트 실패를 새 관측 검증의 통과로 포함하지 않았다.

## 수집·학습

- 교통량: 총 3,000 veh/h, 시작 도로 차선 수 비례 유입.
- 수집: 단일 시뮬레이터, seed 99000부터 103개 독립 회차. 회차당 250초 + 0~119초의 워밍업 뒤 180초 수집.
- 원본 2,422,961개 전이를 수집했다. 충돌·텔레포트 사건 0건.
- 배경차 4종은 유지했다. 현재 비교 대상인 ACC 제외 모델과 맞추기 위해 ACC 전문가 정답 342,268개만 제외했다. 이웃에 ACC가 존재하는 관측은 유지했다.
- 학습 데이터: **2,080,693개**, Krauss 886,311 / IDM 721,904 / EIDM 472,478. 좌/유지/우 정답은 6,733 / 2,063,398 / 10,562개.
- 정지 표본 781,011개, ring 표본 83,936개. 데이터 품질 검사 통과.
- 기존 가중치 없이 seed 0으로 새 hybrid actor를 학습했다. 49→256→256, ReLU, batch 4096, Adam lr 0.0003, 100 epoch, 기존 acceleration MSE + weighted lane CE 유지.
- 학습/검증은 회차 단위 80/20 분리. 검증은 422,287개, 학습은 1,658,406개.
- best validation epoch **95**, 학습 약 **107초**, 정규화를 접은 raw-observation export 일치 검증 통과.

## 같은 데이터 규모의 대조 실험

이전 ACC 제외 데이터에서 같은 seed의 첫 103개 회차를 읽기 전용으로 참조해 대조 데이터를 만들었다. 새 수집과 **208만 개 행의 차량 ID·시각·속도·다음 속도·정답 행동·차종·경로·차선변경 허용 여부가 모두 정확히 일치**했다. 신호·라우팅·ring 등 차량 거리 블록 외의 관측도 정확히 일치했다.

따라서 관측 인코딩을 바꾼 비교가 가능했다. 두 학습은 같은 회차 분리, 표본 수, seed, 네트워크, loss, optimizer, 100 epoch를 사용했다. 검증 최저 loss로 선택했으며 수정 모델은 epoch 95, 기존 인코딩 대조 모델은 epoch 78이 선택됐다. 두 모델 모두 학습을 100 epoch 완료했다.

이번 103개 회차에는 **현재 차선 앞차가 기존에는 없음이었으나 새 관측에서 나타난 표본이 0개**였다. 전문가 자체가 최소간격을 지킨 경우와 부합한다. 따라서 이번 작은 데이터에 현재 차선의 잘못된 없음 표본이 실제로 들어 있었다고 주장하지 않는다. 반면 인접/두 칸 옆 차선의 가까운 차량·겹친 차량 관측을 복원한 행은 587,014개였다. 기존 BC rollout에서 자차가 전문가의 최소간격 아래로 들어가면 앞차 관측이 사라지는 버그는 별도 재현으로 확인했고 이번 수정으로 방지했다.

## 평가 결과

모든 차량 타입 충돌 경계 0.2m. 각 모델을 23개 경로 × 50개 신호 offset × 4개 교통량, 총 **4,600회**씩 평가했다. 동일 seed·배경교통 snapshot 생성 방식(250초 워밍업)·출발 조건·worker 4개를 사용했다.

| 교통량 | 기존 관측 대조 완주율 | 수정 관측 완주율 | 기존 관측 대조 충돌률 | 수정 관측 충돌률 |
|---:|---:|---:|---:|---:|
| 0 | 94.61% (1,088) | 86.35% (993) | 0.00% (0) | 0.00% (0) |
| 1,000 | 73.65% (847) | 72.26% (831) | 14.35% (165) | 1.74% (20) |
| 2,000 | 54.43% (626) | 69.22% (796) | 30.35% (349) | 8.43% (97) |
| 3,000 | 45.74% (526) | 60.78% (699) | 37.04% (426) | 16.26% (187) |

3,000에서 완주율 **+15.04%p**, 충돌률 **-20.78%p**. 2,000에서 완주율 +14.78%p, 충돌률 -21.91%p. 고교통량 추종 안전성은 같은 규모의 대조 모델보다 개선됐다.

다만 신호 위반 종료가 증가했다.

| 교통량 | 기존 관측 대조 신호 위반 | 수정 관측 신호 위반 | 수정 관측 잘못된 차선 종료 |
|---:|---:|---:|---:|
| 0 | 46 (4.00%) | 128 (11.13%) | 29 |
| 1,000 | 109 (9.48%) | 239 (20.78%) | 60 |
| 2,000 | 108 (9.39%) | 190 (16.52%) | 67 |
| 3,000 | 107 (9.30%) | 182 (15.83%) | 82 |

무교통에서도 신호 위반이 증가해 신호 대응 품질 저하가 남아 있다. 고교통량에서는 충돌이 먼저 종료되면 이후 신호 위반 기회 자체가 사라지므로, 두 종료 원인의 비율은 서로 영향을 받는다. 신호 위반 증가 전부를 독립적인 신호 제어 악화로 해석하지 않는다.

이전 대규모 모델과는 표본 수와 학습 update 수가 크게 다르므로 관측 수정 효과는 같은 규모 대조 실험을 우선 해석해야 한다. 수정 모델이 모든 조건에서 이전 모델을 대체할 만큼 개선됐다고 판단하지 않았다.

## 해석과 남은 작업

요청한 세 단계는 완료했다. 공통 관측 버그와 수집/평가 판정 불일치를 해결했고, 고교통량의 충돌 감소가 같은 데이터 규모 대조 실험에서도 나타났다. 관측은 계속 49차원이다.

다만 이 단일 seed 파일럿은 전체 주행 성능의 최종 검증이 아니다. 남은 핵심은 신호 대응과 차선 실패다. 데이터 총량만 늘리면 해결된다고 단정할 근거는 없다. 향후 확대 학습 전 정지선 접근·감속 표본의 조건별 회귀 오차와 학습 update 규모를 점검하는 것이 적절하다. 이번 실행에서 loss 항목이나 새로운 관측 입력을 추가하지 않았다.
