# BC / PPO 공통 관측: bc43

`env/mdp_config.py`의 기본 `OBSERVATION["layout"] = "bc43"`를 사용한다.
단일 환경, 수집기, 병렬 환경 모두 `SumoHighwayEnv`의 동일 관측을 사용한다.

| 인덱스 | 항목 |
|---|---|
| 0 | 속도 / 최대속도 |
| 1–20 | 좌2·좌1·현재·우1·우2 각각 앞차 거리/50, 상대속도/vmax, -뒤차 거리/50, 상대속도/vmax |
| 21–25 | 같은 5개 차선의 물리적 연결성: 없음 -1, 이어짐 1, 끊김은 남은 거리/50 |
| 26–30 | 같은 5개 차선의 전방 차량 밀도 |
| 31–34 | red, yellow, green, 전방 제어 정지선까지 경로상 거리/200 |
| 35–38 | 첫 안내 valid, 현재부터 선택 지점까지 거리/650, sin(angle), cos(angle) |
| 39–42 | 둘째 안내 valid, 현재부터 선택 지점까지 거리/650, sin(angle), cos(angle) |

기본 31차원은 `923430f`의 구성에 맞추며 연결성은 자차의 예정 경로를 조회하지 않는다.
앞차/뒤차가 없으면 각각 [1,1]/[-1,-1]을 사용한다. 기본 항목만 [-1,1]로 제한한다.

2026-11-18부터 새 수집의 `neighbor_distance_mode="bumper"`는 모든 차선의
앞/뒤 차량 거리를 실제 범퍼 사이 거리로 통일한다. SUMO API가 제외한 minGap은
앞차 조회에서는 관측 차량의 값, 뒤차 조회에서는 뒤차의 값을 더해 복원한다.
차량이 가까워지거나 겹쳐도 존재와 상대속도를 유지하며 겹친 거리는 0으로 제한한다.
같은 edge를 직접 스캔하는 ±2 차선은 이미 물리적 거리이므로 다시 보정하지 않는다.
거리 정규화 기준 50m와 관측 차원은 유지한다. 키가 없는 기존 저장 설정은
`legacy` 인코딩을 사용하므로 새 데이터/모델과 혼용하지 않는다.

새 도로 설정의 `EGO["collision_gap_m"]`와 `TRAFFIC["collision_gap_m"]`는 모두
0.2m다. road builder가 차량 타입별 `collisionMinGapFactor`를 계산하므로,
수집·단일 환경·병렬 평가에서 같은 물리적 충돌 경계를 사용한다. 이 설정은
추종 제어의 minGap을 바꾸지 않는다.

신호 상태는 r/R, y/Y, g/G를 각각 인코딩한다. 관측 대상 신호가 없으면 네 값 모두 0이다.
기존 신호 관측 범위 100m를 유지한다. 이 범위와 정규화 기준 200m는 독립 설정이다.
거리는 신호등 기둥 좌표까지의 직선거리가 아니다. SUMO `getNextTLS`의 경로상 거리에
제어 차선의 `stopOffset`을 빼서 차량 앞범퍼부터 실제 제어 정지선까지로 보정한다.
정지선이 없는 비신호 구간이나 장식용 정지선은 신호 대상으로 삼지 않는다.

경로 안내는 연결 가능한 서로 다른 외부 도로가 둘 이상인 지점을 대상으로 한다.
차선별 연결 정답은 입력하지 않는다. 각도는 진입 도로 마지막 접선 대비 진출 도로
첫 접선이며 양수는 왼쪽이다. 고정된 lane 0 형상을 도로 기준으로 사용하므로 차량이
차선을 바꿔도 안내 각도는 변하지 않는다. 단일 출구 강제 합류와 단순 edge 분할은 제외한다.

두 거리 모두 현재 위치 기준이다. SUMO `getDrivingDistance`로 내부 연결 구간까지 포함한다.
교차로 내부에 들어가 이미 지난 선택지는 제거한다. 남은 안내가 없으면 해당 슬롯은 0이다.
거리값은 clipping하지 않으며, 관측 공간에서 거리 세 항목의 상한은 무한대다.

기존 목적지 one-hot, 경로별 차선 연결성, 미래 차선 연결성, 차선변경 여유는 bc43 입력에
포함하지 않는다. 병렬 학습기의 예전 lookahead/차선여유 옵션도 bc43 레이아웃을 바꾸지 않는다.
저장된 이전 실험 설정처럼 layout 키가 없으면 기존 가변 관측 레이아웃을 사용한다.
기존 모델이나 데이터는 차원과 의미가 다르므로 새 BC43 데이터/모델과 혼용할 수 없다.

이 변경은 관측 정의 변경이다. 배경차량별 수집 기능이나 BC에서 PPO로의 가중치 이전 기능을
새로 구현한 것은 아니다.
