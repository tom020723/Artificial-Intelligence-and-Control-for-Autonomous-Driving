# Massively Parallel PPO for SUMO

## 1. 학습 환경 설정

### 도로 복제와 CPU 워커

[도로 설정](../env/road_config.py)으로 [원본 SUMO 도로](../env/road_builder.py)를 만든다. [병렬 환경](../env/parallel_sumo.py)은 서로 연결되지 않은 도로 복제본에 ego를 한 대씩 배치한다. 한 SUMO 프로세스가 여러 도로를 처리하지만, 서로 다른 복제본의 차량은 만나거나 서로를 관측하지 않는다.

| 옵션 | 의미 | 기본값 |
|---|---|---:|
| `--num-envs` | 모든 워커를 합친 도로 복제본 수 | 4,096 |
| `--num-workers` | 독립적으로 실행하는 SUMO 프로세스 수 | 4 |

기본값에서는 워커 4개가 각각 1,024개 도로를 맡는다. 전체 환경 수는 워커 수로 나누어떨어져야 한다. 하나의 정책으로 모든 ego의 행동을 계산한 뒤, 각 워커가 SUMO를 한 스텝 진행한다. 에피소드가 끝난 차량만 재투입한다. 시뮬레이션과 환경 계산은 CPU에서 실행하고, 기본 장치 설정에서는 CUDA를 사용할 수 있으면 정책 추론과 PPO 학습을 GPU에서 실행한다.

### 학습 중 새 에피소드 시작 시 환경 설정

학습 중 각 도로에서 새 에피소드를 시작할 때, 주행 경로·시작 차선·신호 시작 시점을 각각 뽑는다. 이 세 항목과 배경 차량 투입은 하나의 실험 seed에서 나눈 별도의 난수를 사용한다.

- **주행 경로:** Phase 1은 에피소드마다 Ring 미경유 85%·Ring 경유 15%로 그룹을 고른 뒤 그룹 안에서 경로를 균등하게 뽑는다. Phase 2는 같은 비율로 환경을 나누고, 각 그룹 안에서 경로별 환경 수를 균등하게 배정한다. 각 환경은 학습 내내 같은 경로를 달린다. 실제 배정은 결과 폴더의 `training_routes.json`에 저장된다.
- **시작 차선:** `--randomize-departures True`이면 출발 도로의 차선 중 하나를 균등하게 뽑는다. `--randomize-departures False`(기본값)이면 도로 설정의 시작 차선(기본 중앙 차선)으로 고정한다. 경로와 신호의 난수는 그대로 유지된다.
- **배경 차량 시작 차선:** 출발지와 목적지가 정해진 뒤, SUMO가 경로와 무관하게 출발 도로에서 통행 가능한 차선 하나를 무작위로 고른다. 출발 후에는 SUMO가 경로에 맞게 차선을 변경한다.
- **신호 시작 시점:** 125초 주기 안에서 시작 시점을 0.5초 단위로 균등하게 뽑는다. Phase 2에서 교통량이 0보다 크면, 해당 시점의 차량 배치와 신호를 함께 가져온다. 같은 도로의 연동 신호에는 같은 시점을 적용한다.
- **교통량 커리큘럼 (game-inspired traffic curriculum):** `--phase 2`에서만 사용한다. 교통량은 한 복제본의 배경 차량 전체 투입 요청량이다. 모든 환경은 0대/시간에서 시작하고, 에피소드가 끝난 환경만 완주 시 +50대/시간, 실패 시 −150대/시간으로 조절한다(범위 0~3,000대/시간).

Phase 2는 별도 SUMO 프로세스에서 ego가 없는 50~3,000대/시간 기준 도로 60개를 돌린다. 시작할 때 한 번만 시뮬레이션 시간으로 250초간 워밍업하고, 125초 주기의 각 시점에서 교통 상태를 저장해 계속 갱신한다. 새 에피소드는 해당 교통량과 시점의 배경 차량 위치·속도·경로와 신호 상태를 자기 도로에 복원한다. 0대/시간은 빈 도로에서 시작한다.

집중 연습 실험은 `--num-envs 512 --num-workers 4 --focused-envs 144`로 실행한다. 368개 고정 환경은 23개 경로에 16개씩 배정해 기존 커리큘럼을 적용한다. 나머지 144개는 경로와 1,500·2,000·2,500·3,000대/시간의 조합을 매 에피소드 뽑는다. 샘플링 확률은 최근 실패율 추정치에 비례하며, 표본이 적은 조합은 초기 추정치로 보정한다. 조합별 표본 수와 실패 수는 `focus_statistics.json`에 저장된다.

ego 차량의 자동 순간이동은 꺼져있다. (`timeToTeleport="-1"`) 계속 정차해서 에피소드 시간 제한에 도달하면 시간 초과로 기록된다.

### Phase 별 학습

```bash
python train_parallel.py --phase 1 --num-envs 256 --num-workers 4 \
  --steps-per-env 64 --iterations 500 --learning-epochs 10 --minibatch-size 512 \
  --randomize-departures False --eval-interval 0
python train_parallel.py --phase 2
python train_parallel.py --phase 2 --init-model results/parallel_1_YYYYMMDD_HHMMSS_ffffff/model.pt
```

- **Phase 1:** ego 차량 단독으로 배경차량 없이 신호 작동 상황에서 학습
- **Phase 2:** 복제본별 교통량을 완주 여부에 따라 조절하며 배경 차량과 함께 학습한다. 적신호 정차 가점 구간은 Phase 1과 같은 1.5~3.0m다. 너무 멀리 서는 감점은 정지선과 앞차 중 가까운 쪽을 기준으로 한다. `--no-blocked-penalty`를 지정하면 느린 앞차 뒤에서 받는 막힘 감점을 끈다.

| 옵션 | Phase 1 권장값 | Phase 1 예비 |
|---|---:|---:|
| `--num-envs` | 256개 | 512개 |
| `--num-workers` | 4개 | 4개 |
| `--steps-per-env` | 64스텝 | 64스텝 |
| `--iterations` | 500회 | 500회 |
| `--learning-epochs` | 10회 | 10회 |
| `--minibatch-size` | 512스텝 | 1,024스텝 |
| `--randomize-departures` | `False` | `False` |
| `--eval-interval` | 0 (학습 중 정기 평가 끔) | 0 (학습 중 정기 평가 끔) |

워커당 64개 환경을 실행하며, iteration당 16,384스텝을 수집한다. PPO epoch당 미니배치는 32개이고, 총 학습량은 8,192,000스텝이다.


## 3. 모델 평가


결과는 `results/<학습 결과 폴더>/analysis/learning_curve.png`와 `route_evaluation.csv`에 저장된다. 

### 빠른 평가

고유 경로 23개를 신호 시작 시점 50개에서 각각 평가한다 (총 1,150회).

```bash
conda activate sumo
python scripts/evaluate_quick_phase1.py results/<Phase 1 결과 폴더>
python scripts/evaluate_quick_phase2.py results/<Phase 2 결과 폴더>
```

`./results/<학습 결과 폴더>/analysis/quick/learning_curve.png`를 보시면 한 눈에 평가 결과를 확인할 수 있다. 표시되는 정보는 다음과 같다.
- 학습 곡선과 최종 완주율
- 경로별 완주·실패 횟수와 신호 시작 시점별 결과
  - 각 경로는 50개의 서로 다른 신호등 주기에서 시작하는 경로
- 적신호 정차 시 전방 여유 거리의 경로별·전체 평균, 최솟값, P10, Q1, 중앙값, Q3, P90, 최댓값 및 표본 수. 같은 그림의 가로 막대에서 거리 범위와 중앙값을 비교할 수 있다.

Phase 2는 기본적으로 배경 차량 전체 투입 요청량을 0대/시간에서 모델에 저장된 교통량 상한(새 학습 기본 3,000대/시간)까지 100대/시간 간격으로 평가한다. 교통량마다 같은 23개 경로와 50개 시작 시점을 사용한다. `analysis/quick_phase2/learning_curve.png`에서 교통량별 완주율과 정차 거리를 비교하고, `details/vph_XXXX.png`에서 해당 교통량의 경로별 완주·실패, 신호 시작 시점별 결과, 정차 거리 분포를 확인할 수 있다. 빠르게 보려면 `--traffic-step 200`, 한 교통량만 보려면 `--traffic-vph 800`을 지정한다.
