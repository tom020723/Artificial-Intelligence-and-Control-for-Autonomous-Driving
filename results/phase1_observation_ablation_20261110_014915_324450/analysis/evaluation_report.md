## 판정

- 이번 네 실험에서는 **4번(추가 연결성 유지 / 목적지 제거 / 신호 관측 1개, 49차원)**이 가장 좋았다. 직접 OD 22개 및 Ring 경로 ID 5개 전부 성공, 반복 평가 135/135 도착.
- 1번은 23/27 route ID(115/135), 2번은 22/27(110/135), 3번은 20/27(100/135) 성공. 세 모델의 실패는 모두 잘못된 차선 종료이며 충돌·신호 위반·시간 초과는 없음.
- 4번은 163,840스텝 이후 마지막 14회 주기 평가(70 episode)에서도 연속 완주율 100%. 마지막 10 update 평균 value loss는 0.318.
- 4번의 평균 차선 변경 명령 1.22회, 방향 반전 0회. 추가 연결성 도입 전 Phase 1 감점 0.02 모델의 2.30회·방향 반전 2회 대비 개선. 구성 차이가 여러 개이므로 추가 연결성만의 효과로 분리해서 해석하지 않음.
- 목적지 one-hot 없이도 이번 Phase 1의 경로 추종을 수행할 수 있다는 결과다. 목적지 제거가 항상 개선을 만든다는 일반 결론이나 신호 관측 1개가 Phase 2에 충분하다는 증거는 아님.

## 해석 범위

- 각 변형은 하나의 학습 시드만 사용. 특정 관측 삭제의 효과가 여러 학습 시드에서도 재현된다고 단정할 수 없음.
- 고정 출발 조건·무교통 결정론적 반복이므로 seed 0~4를 서로 다른 물리 조건 135개로 해석하지 않음.
- 신호가 모두 청신호인 Phase 1 결과다. 빨간불 정차·청신호 재출발·짧은 간격의 연속 신호 처리 및 배경 차량은 검증하지 않음.
- 신호 관측 1개 모델의 Phase 1 성공만으로 두 번째 신호가 Phase 2에서도 불필요하다고 판단할 수 없음.

## 실패 추적 해석

| 모델 | 실패한 이동 | 동작 |
|---|---|---|
| 1 | A4→A1, A5→A2 | 우측 분기 0번 차선으로 바꾸지 않고 1번 차선 유지. 변경 명령 수락 0회 |
| 2 | A1→A3, A2→A4, Ring 경유 A3→A5 | 필요한 우측 차선 변경을 마지막 단계에 1회만 시도해 분기 차선까지 도달하지 못함 |
| 3 | A2→A4, A4→A1, A5→A2, Ring 경유 A3→A5 | 변경 명령 수락 0회로 잘못된 차선을 유지 |
| 4 | 없음 | 전체 경로 도착 |

- A1→A3/A2→A4/A4→A1/A5→A2에는 직접 OD와 Ring ID가 같은 물리 경로를 가리키는 중복이 있다. 전체 27개 route ID는 23개 서로 다른 edge 경로에 해당한다.
- 실패 직전 추가 연결성에는 오른쪽 분기 차선이 1로 표시되고 현재 차선은 0으로 표시된다. 필요한 안내가 관측에 나타났지만 정책이 변경을 제때 실행하지 않은 양상이다.
- 같은 도로와 안내 관측으로 4번 모델은 모두 성공했으므로, 관측 누락이나 도로 연결 불가능으로 실패했다고 볼 근거는 확인되지 않았다. 학습된 정책의 차이로 보이며, 학습 시드/예산/탐험의 영향을 분리한 후속 비교는 수행하지 않았다.
- 네 모델의 같은 edge 내 방향 반전은 모두 0회. 현재 실패는 반복 왕복 변경이 아니라 필요한 변경을 하지 않거나 늦게 하는 문제다. 실패한 모델의 낮은 변경 횟수를 더 좋은 주행으로 해석하면 안 된다.
