# 실험 4 연장 학습 진단

같은 seed 0~19로 기존 모델과 추가 20만 step 모델을 비교.

| 결과 | 기존 모델 | 추가 학습 모델 |
|---|---:|---:|
| 도착 | 11/20 | 15/20 |
| 적신호 위반 | 3/20 | 3/20 |
| 잘못된 차선 | 6/20 | 2/20 |

위반 seed 0, 6, 14 모두 A3 출발. 가까운 upstream U-turn 신호 nM_A3_0의 직진 신호는 초록이고 중앙 nC 신호는 이미 빨강.
getNextTLS는 두 신호를 모두 반환하지만 _next_signal은 가장 가까운 신호 하나만 관측에 반영.
두 번째 적신호는 100m 이내에 들어와도 policy 입력에 포함되지 않음.
첫 신호 통과 직후 중앙 정지선까지 10.904m, 속도 13.89m/s에서 처음 적신호 관측.
연속 제동거리 v^2/(2b)는 b=5.4m/s²일 때 약 17.864m.
최초 적신호 관측 시점부터 action=[-1,0]으로 최대 제동하는 별도 SUMO 재현에서도 위반 발생.

일부 조기 정차는 추가 학습 후에도 남아 있고 더 멀어진 경우가 있음:
A5→A1 약 13.18m→45.47m, A2→A1 약 7.21m→22.69m (각 모델의 적신호 저속 정차 중 최소 거리).
정차 페널티는 속도 0.5m/s 이하일 때만 적용, 목표 정차 위치를 강제하는 제약은 아님.
초록 통과 보상도 정확한 정차 위치에 직접 의존하지 않음.

우선 개선 대상은 연속 신호 관측(다음 2개 신호 등). 조기 정차는 별도 목표 속도/거리 shaping 실험 필요.
추가 학습이 모든 문제를 해결하지 못한 이유를 학습량만으로 해석하면 안 됨.
