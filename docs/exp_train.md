### observation 구성

총 31차원 / 차선 순서: 좌2 → 좌1 → 현재 → 우1 → 우2

| 인덱스 | 관측 항목 | 차원 |
|---|---|---:|
| `0` | ego 속도 / 제한속도 | 1 |
| `1~20` | 5개 차선별 선행·후행 차량의 상대거리와 상대속도 | 20 |
| `21~25` | 5개 차선의 경로 연결성 | 5 |
| `26~30` | 5개 차선의 전방 차량 밀도 | 5 |

각 차선의 차량정보 4개

| 항목 | 계산 | 차량이 없을 때 |
|---|---|---:|
| 선행차 거리 | 간격 / 50m | 1 |
| 선행차 상대속도 | (선행차 속도 − ego 속도) / 제한속도 | 1 |
| 후행차 거리 | −간격 / 50m | -1 |
| 후행차 상대속도 | (후행차 속도 − ego 속도) / 제한속도 | -1 |

경로 연결성: ego 경로의 다음 도로로 이어지는지.
전방차량밀도?

| 항목 | 의미 / 설정 |
|---|---|
| 관측 거리 | 앞뒤 50m |
| 최종 관측 범위 | `[-1, 1]` |
| 경로 연결성 | 해당 차선이 ego 경로의 다음 도로로 이어지는지 |
| 연결성 값 | 계속 연결: 1 / 끊김: 남은 거리 ÷ 50m / 없는 차선: -1 |
| 전방 차량 밀도 | 전방 차량 수 ÷ (사용 가능한 거리 ÷ 7.5m), 범위 `[0, 1]` |
| 없는 차선의 밀도 | 1 (꽉 찬 차선처럼 처리) |
| history | 현재 프레임 1개, stacking 없음 |
| 기억 구조 | LSTM/GRU 없음, 현재 31차원 입력만 사용하는 MLP |

history는 현재 프레임 1개만 사용 -> observation에 이미 속도가 포함되기 때문에 별도의 stacking필요 없을수도

### reward 구성

| 항목 | 보상 | 적용 조건 / 종료 여부 |

| 충돌 | `-5`로 대체 | 즉시 종료 |
| 도착 | `+2`로 대체 | 즉시 종료 |

| 항목 | 계산 / 설정 |
|---|---|
| 주변 차량 관측 범위 | 앞뒤 50m |
| 차량 상대거리 | 선행: `간격 / 50m`, 후행: `-간격 / 50m` |
| 차량 상대속도 | `(주변 차량 속도 - ego 속도) / 제한속도`, `[-1, 1]`로 clip |
| 주변 차량 없음 | 선행 `[거리, 상대속도] = [1, 1]`, 후행 `[-1, -1]` |
| 경로 연결성 | 다음 경로 도로로 연결되거나 차선 끝이 50m보다 멀면 `1`, 연결되지 않으면 `남은 거리 / 50m`, 없는 차선은 `-1` |
| 전방 차량 밀도 | `전방 차량 수 / (사용 가능한 거리 / 7.5m)`, `[0, 1]`로 clip, 없는 차선은 `1` |
| 신호 관측 | 지정 경로를 따라 가까운 순서로 최대 2개, 관측 범위 100m |
| 신호 거리 | 실제 제어 정지선까지의 거리, `clip(거리 / 100m, 0, 1)` |
| 신호 없음 / 범위 밖 | 상태 `[1, 0, 0, 0]`, 거리 `1` |

### reward

`env/mdp_config.py` 기본값 + `train.py`의 `REWARD_OVERRIDES` 기준.

| 항목 | 보상 | 적용 조건 / 종료 여부 |
|---|---|---|
| 속도 | `+0.1 × (ego 속도 / 제한속도)` | 일반 주행 |
| 앞차 접근 | `-0.1` | 앞차 간격 6m 미만. 관측된 적신호가 있고 속도 0.5m/s 이하이면 면제 |
| 막힘 | `-0.05` | 앞차 간격 20m 미만 + ego 속도가 제한속도의 70% 미만. 적신호 관측 시 면제 |
| 차선변경 | `-0.1` | 좌/우 차선변경 명령이 수락될 때마다 |
| 불가능한 차선변경 명령 | `-0.2` | 차선 없음, 안전 게이트 거절 등으로 명령 실행 불가 |
| 적신호 거리 감점 | `-0.05 × clip(min(앞차 쪽 여유, 정지선 쪽 여유) / 100m, 0, 1)` | 관측된 적신호 중 가장 가까운 신호 기준, 속도 조건 없음 |

| 적신호 위반 | `-5`로 대체 | 스텝 시작 시 적신호였던 정지선 통과, 즉시 종료 |

| 도착 | `+2`로 대체 | 즉시 종료 |
| 잘못된 차선에 갇힘 | 일반 보상에 `-2` 추가 | 다음 경로로 연결되지 않는 차선 끝 5m 이내 + 속도 0.5m/s 미만, 즉시 종료 |
| 충돌/도착 외 ego 소실 | `-2`로 대체 | 오거리 환경에서 즉시 종료 |
| 시간 초과 | 별도 감점 없음 | 1,000 step에서 truncation |

기존 연결성은 바로 다음 route edge로 이어지는지만 확인. **각 후보 차선에서 다음 두 도로까지 차선 변경 없이 이어지는지**를 추가로 관측하도록 구현함.

| 항목 | 구성 |
|---|---|
| 기존 연결성 | ±4차선 9차원. 기존 계산·종료 판정 유지 |

| 값 | 차선 없음 −1 / 무변경 연결 경로 없음 0 / 연결 경로 있음 1 |
| 조회 시점 | 도로 끝 50m 제한 없이 출발 지점부터 제공 |
| junction 내부 | 현재 내부 차선의 실제 진출 링크를 조회. 여러 내부 edge로 나뉜 연결도 처리 |

- 실패한 경로에서도 추가 연결성에는 올바른 우측 차선이 1로 표시됐음. 안내가 있었지만 정책이 활용하지 못한 양상.
- 4번은 163,840 step 이후 마지막 14회 주기 평가(70 episode)에서도 연속 완주율 100%.
- **4번을 최신 Phase 1 기준 및 다음 Phase 2 시작 모델로 선택.** 이전 50차원·감점 −0.02 모델 대비 완주율 유지, 평균 변경 명령 2.30→1.22회.
- 차원이 작을수록 성능이 일관되게 좋아진 결과는 아님. 각 변형은 학습 시드 하나이며, 입력 차원 변화에 따른 초기 가중치 차이도 있어 삭제 효과를 일반화할 수는 없음.
- 모두 청신호인 Phase 1 평가이므로, 신호 관측 1개가 Phase 2의 연속 신호에도 충분한지는 별도 확인 필요.

## 최신 모델의 observation·reward

**선택한 4번 및 진행 중인 Phase 2의 저장 설정 기준.** 작업 폴더 기본 관측은 59차원이므로 재생 시 `--saved-config`로 해당 모델의 설정을 복원해야 함.

### Observation: 총 49차원

| 인덱스 | 항목 | 차원 |
|---|---|---:|
| `0` | ego 속도 / 제한속도 | 1 |
| `1~20` | 좌2~우2의 선행·후행 차량 거리와 상대속도 | 20 |
| `21~29` | 좌4~우4 기존 연결성: 바로 다음 도로 기준 | 9 |
| `30~34` | 좌2~우2의 전방 차량 밀도 | 5 |
| `35~38` | 첫 번째 신호 상태 one-hot `[안보임, 초록, 노랑, 빨강]` | 4 |
| `39` | 해당 신호의 정지선 거리 / 100m, `[0, 1]` clip | 1 |
| `40~48` | 좌4~우4 추가 연결성: 다음 두 도로까지 무변경 연결 | 9 |

- 목적지 one-hot·두 번째 신호 관측 없음. history stacking 없음.
- 차량 관측 범위 앞뒤 50m, 신호 관측 범위 100m. 신호가 안 보이면 상태 `[1, 0, 0, 0]`, 거리 1.
- 기존 연결성은 도로 끝 50m 초과·junction 내부에서 1 처리하는 동작 유지. 추가 연결성은 거리 제한 없이 실제 링크를 확인함.

### Reward: 최신 Phase 2 기준

| 항목 | 보상·감점 / 조건 |
|---|---|
| 속도 | `+0.1 × ego 속도 / 제한속도` |
| 앞차 접근 | 간격 6m 미만 −0.1. 관측된 적신호 + 속도 0.5m/s 이하이면 면제 |
| 막힘 | 앞차 20m 이내 + 속도 제한속도의 70% 미만이면 −0.05. 적신호 관측 시 면제 |
| 수락된 변경 명령 | 비제로 차선 변경 명령당 **−0.02** |
| 거절된 변경 명령 | 비제로 명령당 −0.2 |
| 적신호 거리 감점 | **`−0.1 × clip(min(앞차 여유, 정지선 여유) / 100m, 0, 1)`**. 속도 조건 없음 |
| 앞차 / 정지선 여유 | 각각 `max(앞차 간격 − 3m, 0)` / `max(정지선 거리 − 3m, 0)`. 앞차가 없으면 앞차 여유는 무한대 |
| 청신호 정지선 통과 | 경로에 맞는 통과 +10, 신호 ID당 에피소드 1회 |
| 적신호 위반 / 충돌 | −5로 대체, 즉시 종료 |
| 도착 | +2로 대체, 종료 |
| 잘못된 차선 | 일반 보상에 −2 추가. 다음 도로로 연결되지 않는 차선 끝 5m 이내 + 속도 0.5m/s 미만이면 종료 |
| 충돌·도착 외 ego 소실 | −2로 대체, 종료 |
| 시간 초과 | 별도 감점 없음, 1,000 step에서 truncation |

거리 감점 0.1은 조기 정차를 줄이기 위한 **비교 실험값**이며, 계산으로 도출한 최적값은 아님. 앞차가 없는 정지선 20m 앞에서 스텝당 거리 감점은 0.0085→0.017로 증가함.
