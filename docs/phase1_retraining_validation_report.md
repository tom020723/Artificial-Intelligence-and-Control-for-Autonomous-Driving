# Phase 1 재학습 검증 결과 분석

검증일: 2026-11-17.

## 1. 결론

**동일한 설정으로 학습한 세 모델 중 seed 1에서 신호 위반과 청신호 미출발이 발생했다. 현재 학습 방법은 seed가 달라도 안정적으로 성공한다는 목표를 충족하지 못했다.**

seed 0·2는 각각 2,300회 모두 완주했다. 그러나 seed 0에는 조기 정차 후 재접근, seed 2에는 정지선 약 1cm 앞 정차가 남아 있다. 완주율이 높아도 정차·재출발 행동의 품질까지 확보됐다고 보기 어렵다.

세 모델은 관측·보상·학습량을 같게 두고 seed만 바꾸어 무작위 초기화부터 학습했다. seed당 학습량은 62,914,560스텝이다. 정상 신호·무교통·랜덤 출발 차선에서, 고유 경로 23개와 신호 시작 시점 50개의 조합을 두 세트(development·holdout)로 평가했다. 세트당 1,150회, 전체 6,900회이며 같은 경로·시점 순번의 출발 차선은 세 모델에서 동일하다. 두 세트는 신호 시점을 나눈 것으로, 학습 분포와 전혀 다른 환경을 검증한 것은 아니다.

## 2. 완주와 실패 분포

| seed | development 완주 | holdout 완주 | 신호 위반 합계 | 시간 초과 합계 |
|---|---:|---:|---:|---:|
| 0 | 1,150/1,150 (100%) | 1,150/1,150 (100%) | 0 | 0 |
| 1 | **1,079/1,150 (93.83%)** | **1,079/1,150 (93.83%)** | **42** | **100** |
| 2 | 1,150/1,150 (100%) | 1,150/1,150 (100%) | 0 | 0 |

충돌·잘못된 차선에 의한 종료·원인 불명 종료는 모든 모델에서 0회였다. seed 0·2는 모든 경로에서 세트별 50/50 완주했다.

seed 1의 실패는 다음 세 경로에 집중됐다.

| 경로 | development | holdout | 해석 |
|---|---|---|---|
| A3→A5 | **50/50 시간 초과** | **50/50 시간 초과** | 평가한 모든 출발 차선·신호 시점 조합에서 반복 실패 |
| A3→A4 | 신호 위반 20건 | 신호 위반 19건 | 정지선 접근·제동 실패 |
| A3→A2 | 신호 위반 1건 | 신호 위반 2건 | 일부 조건에서 신호 준수 실패 |

실패가 두 평가 세트에서 반복되고 특정 경로에 집중된다는 점에서, 전체 평균만으로 판단하기 어려운 경로별 취약성이 드러난다. seed 2의 성공으로 seed 1의 실패를 제외할 수 없으며, 세 모델을 평균낸 완주율도 재현성 통과의 근거가 되지 않는다.

## 3. seed 1: 청신호 미출발과 정지 상태 보상

A3→A5, 출발 차선 0, 신호 offset 1초 사례를 재생하면 차량은 A3_in에서 정차한 뒤 500초 제한까지 출발하지 않는다. 174.5·299.5·424.5초에 관측된 청신호 구간에서도 속도 0을 유지했다. 따라서 이 경로의 시간 초과에는 **실제 청신호 미출발**이 존재한다.

후반 100스텝 역시 모두 정지 상태였지만 보상 합은 약 **+9.67**이었다. 마지막 적신호 스텝에는 속도 추종 가점이 약 **+0.0967** 지급됐다. 정지 상태에서도 양의 보상을 얻는 구간이 있음을 보여준다.

이 결과는 현재 보상에서 **주행 완료와 대기 상태 유지의 유인이 충분히 구분되는지** 검토할 근거다. 다만 해당 가점이 미출발을 유발한 단일 원인이라고 입증한 것은 아니다. 같은 상황에서 성공한 seed 0·2의 관측·행동·보상과 비교해야 인과관계를 좁힐 수 있다.

A3→A4의 출발 차선 1, offset 1초 사례에서는 28.5초에 적신호 위반 종료를 재현했다. 청신호 미출발뿐 아니라 정지선 접근에서도 실패하므로, 한 가지 정차 거리 지표만 개선해서 해결될 문제라고 단정하기 어렵다.

근거: [청신호 미출발 trace](../experiments/phase1_validation_20261117/seed1/analysis/validation_traces/timeout.csv), [신호 위반 trace](../experiments/phase1_validation_20261117/seed1/analysis/validation_traces/redlight_evaluation_case.csv).

## 4. 정차 거리: 전체 분포와 경로별 차이

단위는 m다. P90은 표본의 90%가 그 값 이하라는 뜻이다.

| seed | 세트 | 마지막 적신호 정차 n / 중앙값 / P90 | 최초 황·적신호 정차 n / 중앙값 / P90 |
|---|---|---|---|
| 0 | development | 702 / 2.310 / 2.635 | 702 / 2.381 / 2.635 |
| 0 | holdout | 700 / 2.309 / 2.558 | 700 / 2.380 / 2.635 |
| 1 | development | 714 / 1.829 / 2.782 | 714 / 2.370 / 3.207 |
| 1 | holdout | 712 / 1.829 / 2.782 | 712 / 2.370 / 3.172 |
| 2 | development | 705 / 2.441 / 2.667 | 705 / 2.482 / 2.832 |
| 2 | holdout | 701 / 2.450 / 2.667 | 701 / 2.482 / 2.832 |

모든 모델의 전체 중앙값·P90은 사전 기준인 중앙값 1.5~4m, P90 5m 이하에 들어간다.

그러나 seed 1은 경로별로 보면 지나치게 가까이 정차한다. development의 마지막 적신호 정차 중앙값은 A1→A2 약 0.645m, A4→A5 약 0.543m로 경로별 기준을 충족하지 못했다. 전체 중앙값만 보면 이런 경로별 실패가 가려진다.

seed 0·2는 표본 수 n ≥ 10인 경로에서 중앙값·P90 기준을 충족했다. 그러나 아래의 접근 과정과 극단 사례는 이 기준만으로 걸러지지 않았다.

### seed 0: 멀리서 저속·정차한 뒤 다시 접근

A3→A5, 출발 차선 2, offset 53.5초에서는 황색에 감속한 뒤 정지선 약 **34.8m 앞에서 속도 0.5m/s 이하**가 됐다. 잠시 저속·정차한 뒤 적색 상태에서 다시 전진했고, 최종적으로 약 **2.45m 앞에 정차**한 뒤 청신호에 출발해 완주했다.

이는 신호가 바뀔 때까지 34.8m 앞에 계속 서 있던 사례는 아니다. 감속 과정에서 일찍 멈췄다가 다시 접근한 사례다. **최종 정차 위치가 적절하더라도 접근 과정은 매끄럽지 않을 수 있다.** 최초 정차 거리가 5m를 넘은 사례는 development 10건, holdout 13건이었다.

근거: [조기 정차 후 재접근 trace](../experiments/phase1_validation_20261117/seed0/analysis/validation_traces/case_00.csv).

### seed 2: 신호를 지켰지만 정지선 여유가 거의 없음

A5→A5, 출발 차선 1, offset 106초에서는 황색 접근 후 정지선 **약 0.00947m(0.95cm) 앞**에 정차했다. 적색 정지선을 넘지 않아 위반으로 집계되지 않았지만, 목표 여유 거리 1.5~3m에는 크게 못 미친다.

seed 2의 최초 정차 거리가 5m를 넘은 사례도 두 세트에 각각 1건 있었고, development 최댓값은 약 23.50m였다. 따라서 이 모델은 **현재 수치 기준은 통과했지만, 최소 정차 여유와 접근 품질에는 개선이 필요하다.** 중앙값·P90과 함께 최솟값 및 극단 사례를 봐야 한다.

근거: [정지선 근접 정차 trace](../experiments/phase1_validation_20261117/seed2/analysis/validation_traces/case_07.csv).

정차 통계는 episode마다 마지막 측정 가능한 적신호 정차와 최초 황·적신호 정차를 집계한 값이다. 모든 신호 접근과 정차를 빠짐없이 측정한 값은 아니며, 속도 0.5m/s 이하를 정차로 분류하므로 저속 이동도 포함할 수 있다.

## 5. 재출발: 실제 실패와 측정 오류가 함께 존재

| seed | 세트 | 재출발 관측 대상 | 미출발 원시 집계 | 출발을 관측한 사례의 지연 P90 |
|---|---|---:|---:|---:|
| 0 | development | 702 | 39 | 0.5초 |
| 0 | holdout | 700 | 39 | 0.5초 |
| 1 | development | 693 | 168 | 0.5초 |
| 1 | holdout | 693 | 168 | 0.5초 |
| 2 | development | 705 | 0 | 0.5초 |
| 2 | holdout | 701 | 0 | 0.5초 |

seed 0의 미출발 39건은 세트마다 모두 A4→A5에서 기록됐다. 대표 사례에서는 다음과 같이 정상 출발했다.

| 시각 | 속도 | 관측된 변화 |
|---|---:|---|
| 74.5초 | 0m/s | 청신호 전환, 차선 1의 신호 연결 번호 25 |
| 75.0초 | **2.458m/s** | 출발과 동시에 차선 2로 변경, 신호 연결 번호 26 |
| 75.5초 | 4.934m/s | 정상 신호 통과 |

평가기에서는 신호 ID와 연결 번호가 모두 같아야 재출발 추적을 이어간다. 차선 변경으로 연결 번호가 25→26이 되자 출발을 인정하지 않고 추적을 끝냈다. **대표 사례의 미출발 집계는 측정 오류**다. 다만 seed 0의 78건 전체가 같은 원인이라고 확정하거나 원시 값을 0으로 보정하지는 않았다.

seed 1의 미출발 168건에도 측정 오류가 섞일 수 있다. 그러나 A3→A5의 실제 청신호 미출발과 신호 위반은 별도 trace로 확인했으므로 측정 오류로 제외할 수 없다. 또한 지연 P90 0.5초는 출발을 관측한 사례만의 값이므로, 미출발 사례가 있는 모델의 재출발 성능을 대표하지 않는다.

근거: [seed 0 신호·차선 상세 기록](../experiments/phase1_validation_20261117/seed0/analysis/validation_traces/restart_link_diagnostic.json).

## 6. 결과가 시사하는 문제

| 확인한 현상 | 결과로 판단할 수 있는 내용 | 아직 확정할 수 없는 내용 |
|---|---|---|
| seed 1만 경로별 반복 실패 | 동일 설정의 학습 결과가 seed에 민감함 | 실패를 유발한 단일 관측·보상 항목 |
| 정지 상태에서도 속도 추종 가점 지급 | 대기 중 보상과 주행 목표의 관계를 검토할 필요 | 이 가점만 제거하면 미출발이 해결되는지 |
| seed 0의 조기 정차 후 재접근 | 최종 정차 거리만으로 접근 품질을 평가하기 어려움 | 관측 불연속·황색 대응 중 어느 요인이 지배적인지 |
| seed 2의 약 1cm 앞 정차 | 위반 0회와 충분한 정차 여유 확보는 서로 다른 성능 | 드문 근접 정차를 얼마나 안정적으로 억제할 수 있는지 |
| 차선 변경 시 재출발 추적 중단 | 미출발 원시 집계에 오탐이 포함됨 | 현재 미출발 집계 전체의 실제 실패 비율 |

현재 결과는 **학습 재현성, 신호 접근·재출발 행동, 평가 지표**를 각각 구분해 분석해야 함을 보여준다. seed 0·2의 성공만 선택해 현재 설정을 완료 모델로 판단하기 어렵다. 후속 분석의 중심은 seed 1의 고정 실패 경로와 성공 seed의 같은 상황 비교, 그리고 미출발 집계의 오탐 분리다.
